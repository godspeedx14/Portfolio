Project 5: LoadAssigner

A Online portal to collect Teacher’s Choices and Admin panel.Assign Best teacher for each subject, based on their Choice and their past performance.Ensure everyone get an balance workload.Admin panel to inc/dec workload , increase no. of teachers in a subject.... It will lead to a web page that has option to signin using Gmail account. By using it teachers can set their preferences of subjects and their info related to that subject, which will calculate a score for them . All this info is stored in our database. And in an Excel sheet available to admin. Home page of website also have admin section that can be accessed by clicking on small gear symbol ⚙️ on top right corner that will toggle admin section: (username: admin , password:123) this will allow you to see table for each subject with ranking of teachers in it. In backend, whenever Admin pannel is accessed it pull all teachers name from backend and create a object data structure for each subject that holds a fix no. Of teachers in it . When a teacher is pulled from database, it try to place it in teacher's first preference, if there's empty space in that subject the teacher gets inserted in it otherwise new teacher try to replace a already existing teacher based on score, if successful the already existing teacher is removed and a new location is allocated to him based on his preferences. However if the new teacher is not able to replace anyone of old teacher in the subject then his next preference is checked for another subject and same process is repeated till he gets placed. Every teacher is placed in one or more subjects as per admin need.
